# Pruebas históricas de Claude

Este directorio concentra pruebas, sandboxes, fixtures y datos de prueba creados durante las iteraciones previas del proyecto.

No forma parte del prototipo de Parkour V3. Se conserva como referencia histórica y sus rutas internas fueron actualizadas para permanecer consultables bajo `archive/claude_tests/`.

El directorio activo `scenes/test/` quedó vacío y reservado para las pruebas nuevas de V3.
